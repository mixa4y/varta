VARTA: roadmap окремих чатів

Ціль: local web UI на loopback → application services → SQLite і managed filesystem → локальні workers → відтворювані Evidence Map, reports та sealed exports. Notion не входить до системи.

Керований запуск Codex tasks

Offline-перегляд. Для кнопок Start відкрийте START_ROADMAP.cmd.

OFFLINE PLAN

Двофазний gate: технічний PASS ще нічого не публікує. Після нього окрема підтверджена кнопка запускає Git audit → exact staging → commit → push у codex/* → Draft PR. Наступний залежний stage відкривається лише після статусу GITHUB SYNCED; merge, tag і release залишаються окремими ручними рішеннями.

Processor lane після C10

P01 — OCR/text processor

Залежності: C05, C08, C10

Local OCR, page mapping, versioned params, confidence/errors. Тести: українські/англійські synthetic pages, rotation, blank/corrupt PDF, missing dependency, timeout і provenance.

P02 — КЕП/P7S та attachments

Залежності: C05, C08, C10

Literal PDF/P7S pairing, local verification, not_verifiable, claimed-vs-actual attachments. Тести: valid/invalid/missing/ambiguous pairs, no private keys/log leaks.

P03 — Offline STT

Залежності: C05, C08, C10

FFmpeg-derived normalization, local Whisper, timestamps/confidence, interruption policy. Тести: Ukrainian synthetic audio, silence/corrupt media, offline load, retry/provenance.

P04 — Matching/anomalies

Залежності: C08, C10

Versioned exact/metadata/text matching, confidence і structured findings без fraud/legal auto-conclusion. Тести: true/false/ambiguous pairs, thresholds, deterministic results, preserved review.

Найближчий новий чат: VARTA C01 — стабілізація поточного working baseline.
До його PASS не починати масовий refactor, новий UI framework, full Evidence Map generator або release packaging.
