## Мета

Зіставити додатки, заявлені в основному документі, з фактично наявними файлами, сторінками, архівними елементами та окремими реєстровими документами.

## Джерела заявлення

- згадка в основному тексті;
- розділ або список додатків;
- опис у супровідному документі;
- manifest архіву;
- зовнішній реєстровий запис, якщо його походження відоме.

## Фактичне представлення

- окремий файл у пакеті;
- сторінки всередині основного PDF;
- елемент вкладеного архіву;
- окремо зареєстрований документ;
- лише посилання без доступного вмісту.

## Алгоритм

1. Витягнути declarations із посиланням на фрагмент джерела.
2. Сформувати inventory фактичних кандидатів.
3. Нормалізувати назви лише для пошуку; оригінальні назви зберегти.
4. Зіставити за хешем, назвою, типом, кількістю сторінок, текстом і реквізитами.
5. Зберегти candidates, scores, limitations і результат.
6. Передати неоднозначні випадки на ручну перевірку.

## Результати

- `declared_and_present`
- `declared_but_missing`
- `present_but_undeclared`
- `possible_duplicate`
- `possible_version`
- `name_mismatch`
- `content_mismatch`
- `page_count_mismatch`
- `manual_review_required`

## Правила висновку

Назва сама по собі не підтверджує відповідність. Відсутність окремого файла не означає відсутність додатка, поки не перевірені сторінки й архіви. Розбіжність описується як технічний finding; юридичну оцінку надає користувач.
