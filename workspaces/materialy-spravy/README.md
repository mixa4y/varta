# Матеріали справи

`corpus/` — незмінні документи та підписи з наданого користувачем архіву.
Користувач 2026-09-13 прямо дозволив включення цього корпусу до відкритого
репозиторію VARTA. Агенти можуть читати його без додаткового дозволу.

`materialy.json` містить контрольну суму вихідного архіву та кількість файлів.
Локальні налаштування програми: `settings.json` (R05PrivateSettingsStore).
SQLite та керовані копії імпорту: `runtime/`; вони не включаються до Git.
Оригінальний архів та literal names документів збережено незмінними.
